# st — zastosowane patche

> Build oparty na **Luke Smith's build of st**

| Patch | Opis |
|---|---|
| **scrollback** | Przewijanie historii `alt-↑/↓`, `alt-pageup/down` |
| **vim bindings** | Przewijanie `alt-k/j/u/d` |
| **zoom/font size** | Zmiana rozmiaru fontu `alt+shift` |
| **clipboard** | Kopiowanie `alt-c`, wklejanie `alt-v` |
| **externalpipe** | URL handling `alt-l/y/o` |
| **xresources** | Kolory i alpha z `~/.Xresources` / `~/.Xdefaults` |
| **alpha/transparency** | Przezroczystość, zmiana `mod-s/a` |
| **boxdraw** | Lepsze renderowanie znaków ramek |
| **ligatures** | Obsługa ligatur (harfbuzz) |
| **font2** | Alternatywny font fallback |
| **blinking cursor** | Obsługa kursora migającego (Ps 0-8) |
