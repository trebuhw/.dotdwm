# Patche w moim dwm

| Patch | Co robi |
|---|---|
| **systray** | pasek systemowy (ikony w barze) |
| **autostart** | uruchamia `autostart.sh` i `autostart_blocking.sh` przy starcie |
| **movestack** | `movestack.c` — przesuwanie okien w stosie (`Shift+↑/↓`) |
| **shiftview** | `shiftview.c` — przełączanie tagów w kółko |
| **selfrestart** | `selfrestart.c` — restart dwm bez wylogowania (`Super+Shift+Q`) |
| **placemouse** | umieszczanie okna myszką w układzie tiling |
| **moveorplace** | `Mod+LPM` — move dla float, place dla tiled |
| **fullscreen** | dedykowany fullscreen (`Super+Shift+F`) |
| **gaps** | odstępy między oknami (`setgaps`) |
| **smartgaps / smartmode** | automatyczne ukrywanie przerw/ramek (`Super+G`) |
| **floatborderpx** | osobna grubość ramki dla pływających okien (w rules) |
| **viewontag** | przy przełączeniu taga automatycznie przełącza widok |
| **refreshrate** | ogranicznik FPS dla move/resize (120Hz) |
| **transient** | `transient.c` — obsługa okien transient (dialogi) |
| **savefloats** | zapamiętuje rozmiar/pozycję okna float przed wciągnięciem do tilingu |
