# CheatSheet #
# Midnight Commander - Twoja konfiguracja

# zaznaczanie (custom keymap)
  Ctrl            A         *zaznacz wszystko* (dialog z wzorcem, domyślnie *)
  Ctrl            D         *odznacz wszystko* (dialog z wzorcem)
  Insert                    *zaznacz/odznacz podświetlony plik*
  Ctrl            T         *zaznacz/odznacz podświetlony plik*
  Ctrl            E         *nowy plik* (otwiera edytor, zapisz pod nazwą)
  Ctrl            Y         *ulubione katalogi* (hotlist)
  Ctrl            \         *ulubione katalogi* (domyślny skrót)

# panele plików
  Tab                       *przełącz panel* (lewy/prawy)
  Alt             I         *ta sama ścieżka w drugim panelu* (mirror)
  Alt             .         *pokaż/ukryj pliki ukryte*
  Alt             T         *zmień widok panelu* (Pełny/Skrócony/Długi)
  Alt             ,         *zmiana układu paneli* (pionowy/poziomy)
  Ctrl            R         *odśwież zawartość katalogu*
  Ctrl            Space     *pokaż rozmiar katalogu*
  Ctrl            O         *pokaż/ukryj panele* (podgląd terminala)

# operacje na plikach
  F3                        *podgląd pliku*
  F4                        *edycja pliku*
  F5                        *kopiuj*
  F6                        *przenieś / zmień nazwę*
  Shift           F6        *zmień nazwę* (zawsze na podświetlonym, ignoruje tagi)
  F7                        *nowy katalog*
  F8                        *usuń*
  F9                        *menu główne*

# linia poleceń
  Alt             Tab       *autouzupełnianie ścieżki/polecenia*
  Alt             Enter     *wstaw ścieżkę podświetlonego pliku*
  Alt             A         *wstaw ścieżkę bieżącego panelu*
  Alt      Shift  A         *wstaw ścieżkę drugiego panelu*
  Alt             C         *szybka zmiana katalogu*
  Alt             P         *poprzednie polecenie z historii*
  Alt             N         *kolejne polecenie z historii*
  Alt      Shift  H         *pokaż historię poleceń*
  Ctrl            S         *szybkie wyszukiwanie w panelu*

# skróty złożone Ctrl+X
  Ctrl X          C         *chmod - zmiana uprawnień*
  Ctrl X          O         *chown - zmiana właściciela*
  Ctrl X          L         *utwórz twardy link*
  Ctrl X          S         *utwórz link symboliczny*
  Ctrl X          P         *wstaw ścieżkę aktywnego panelu do linii poleceń*

# edytor (mcedit, F4)
  F3                        *rozpocznij zaznaczanie tekstu / drugi raz = koniec*
  F5                        *kopiuj zaznaczenie*
  F6                        *przenieś zaznaczenie*
  F8                        *usuń zaznaczenie*
  Ctrl            S         *włącz/wyłącz podświetlanie składni*
  Ctrl            U         *cofnij (undo)*
  Ctrl            Y         *usuń całą linię*
  Alt             K         *przełącz zakładkę w linii*
  Alt             L         *idź do linii o numerze*
  Alt             Q         *wstaw znak dosłowny* (np. Tab, Esc)

# User Menu (F2)
  F2              T         *otwórz bieżący katalog w Ghostty*
  F2              C         *kopiuj pełną ścieżkę podświetlonego pliku*
  F2              N         *kopiuj samą nazwę podświetlonego pliku*
  F2              B         *kopia zapasowa pliku z datą na początku nazwy*
  F2              K         *pokaż skróty klawiszowe mc (rofi)*
